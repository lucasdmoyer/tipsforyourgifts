# Exact release approvals

These records preserve a founder decision without broadening it.

Each JSON record binds an owner-authored GitHub approval to one pull request head, one publication content set, one reviewed Firebase preview, and one allowed action. Validation fails if the exact-head merge boundary or any excluded authority is weakened.

An approval record is not a production receipt. It does not authorize IAM, credentials, Firebase production deployment, affiliate expansion, social publishing, email, spend, a changed pull request head, a merge commit, a replay, or a later artifact. Production truth remains in `releases/receipts/` and `config/live-publication.json`.
