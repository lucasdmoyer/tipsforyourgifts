# Research mission receipts

Each founder-started Codex research workflow creates one trusted mission envelope here before the model receives a key. The independent review job completes that same record only after the exact run, article, social pack, and QA receipt pass deterministic validation.

A completed mission means the research team finished and release preparation can begin. It does not mean the pull request merged, Firebase production changed, an affiliate account was enabled, or a social post was published.
