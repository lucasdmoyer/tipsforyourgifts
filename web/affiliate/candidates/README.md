# Affiliate link candidates

Founder-dispatched, program-issued paid URLs are stored here only after an affiliate program is enabled. Each immutable record binds one ordinary editorial winner to its article, research run, independent article review, program revision, exact paid destination, approved tracking mechanism, and credential-free product-identity evidence. Tracking may be carried directly in approved query parameters or in a verified path that redirects to an approved partner parameter; the validator must prove the real identity survives the redirect.

A candidate does not change generated content, approve itself, authorize a deployment, or make a link live.
