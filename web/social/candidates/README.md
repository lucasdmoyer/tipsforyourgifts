# Social creative candidates

These records bind an original generated creative to one exact draft, pack hash, post hash, local Firebase asset path, future stable production URL, byte digest, dimensions, alt text, and automated visual checks.

A candidate is not a rights approval, content approval, publication authorization, or external post. It can become an approved media record only after the exact asset is visible at its stable owned URL and Lucas records current rights evidence through the protected media-approval workflow.
