# Social approval receipts

This directory contains immutable, hash-bound founder approval receipts created only after a channel is configured and an exact byte-verified media record exists. A receipt binds that media record to the reviewed copy, destination, disclosure, pack, post, and the destination article's current publication-manifest entry. If an approved paid-link overlay is added, removed, or changed on that article, the receipt becomes stale and the post must be approved again. It is not proof that a post was published.

Do not put credentials, access tokens, private account data, or copied third-party media here.
