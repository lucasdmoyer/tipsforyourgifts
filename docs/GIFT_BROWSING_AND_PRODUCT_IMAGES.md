# Gift browsing and product images

The `/gifts` page shows researched guides and filters them by the same item's budget band, topic and recipient fit. A budget match uses the top of the documented single-product range, not a current seller price, pair subtotal or checkout quote. Only the base URL belongs in the sitemap; matching URLs such as `/gifts?topic=outdoors&budget=50&for=mom` are useful as share links, not new search landing pages. Query changes do not add tracking. New published guides need explicit coverage in `web/src/app/gift-browse.ts`; do not mark a product as suitable for children without the separate editorial/safety review.

Each recommendation guide links back to one or more relevant browse categories. Treat this as a reader-navigation improvement, not evidence of acquisition or conversion. Start measuring with seven finalized days of Search Console page data; once there is a baseline, test one founder-approved share campaign into a specific guide and compare its own platform-reported outbound clicks separately from organic Google clicks. Do not attribute orders to either campaign without permitted affiliate reporting.

## Product image intake

1. Match the photo or packaging to the exact product model, edition, ISBN or platform. Confirm the seller click goes to the product already covered by the research. A screenshot of the merchant’s site is not a reuse grant.
2. Record a publisher press-kit grant that permits the proposed use, written rightsholder permission, or original photo provenance. Keep exact source and license evidence with the product identity, and allow a reviewer to check it independently. Do not use manufacturer photos from a standard listing as a shortcut. No generic or generated substitute may be called an actual product image.
3. For an authorized first-party asset, serve a small, accessible WebP from `/product-images/` with the first 12 hex characters of its file SHA-256 in its name. Record its public file fingerprint, source fingerprint, dimensions, alt, and credit in `web/visuals/product-images.json`. The release manifest binds that registry and exact file bytes. Keep illustrations separate and label them.
4. Run `npm run validate`, `npm run build`, and `npm run smoke`. Verify the real image loads before the article explainer, the destination label matches the link, disclosure stays above a paid recommendation, and the article does not repeat the same image. If rights expire, remove the entry and its file together.

## Provider decisions

- **Codenames 2025 English edition:** Czech Games Edition's [press resources](https://www.czechgames.com/for-press-games) explicitly invite editorial web use; the [exact product press kit](https://www.czechgames.com/for-press-games/codenames) identifies CGE00125/EAN 8594156311254. The sample is its official rendering of the actual box, not a photograph and not an affiliate placement.
- **Trees of Eastern North America paperback (ISBN 9780691145914):** Princeton University Press [permits publicity use of its high-resolution covers](https://press.princeton.edu/resources/media-journalists). We use the [exact edition's publisher cover](https://press.princeton.edu/books/paperback/9780691145914/trees-of-eastern-north-america) with credit, linked to the unchanged ordinary destination. This permission does not extend to the magnifier or to other publishers’ covers.
- **Sapiens U.S. paperback (ISBN 9780063422001):** [Bookshop's Featured Book Widget](https://bookshop.org/info/embed/links-and-widgets) is a candidate for the cover and seller badge. The existing approval is for the exact outbound link, not a widget, external browser requests or live price. Capture the native code for that ISBN and review cookie, privacy, frame, price and disclosure behavior before considering a separate approval. An ordinary product link is not a license to copy the cover by itself.
- **Amazon:** the affiliate program is not enabled here. [Creators API image rules](https://affiliate-program.amazon.com/help/operating/policies) prohibit caching API image bytes and restrict caching image URLs. Never vendor Amazon assets into Firebase. An accepted account, exact product ID, approved link and compliant fresh delivery are separate gates.
